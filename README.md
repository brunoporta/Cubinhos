# Cubinhos — Android

Projeto Cubinhos para Android, compilado automaticamente pelo GitHub Actions.
O codigo-fonte original esta no arquivo compactado `Cubinhos_source.tar.xz.b64`, preservado sem alteracoes no aplicativo web. O fluxo `.github/workflows/build-apk.yml` extrai os arquivos e gera um APK debug assinando automaticamente com Gradle.
